# 校园快取通 Campus Express

面向四川师范大学**成龙校区**与**狮子山校区**的校园快递代取平台（开发中）。目前独立开发，不再依赖 Base44。

**当前版本：V0.3.0 本地业务测试版。真实下单、身份认证、支付和正式运营均未开放。**

## 运行 V0.3 后端原型

安装 Node.js 24.12 或更新版本，在本项目目录运行 `npm start`，再打开 <http://127.0.0.1:3000>。无需安装 npm 包。使用虚构测试账号、`TEST-1234` 和包含“测试”的楼下交接点；运行 `npm test` 可执行后端验证。完整范围与下一阶段工作见 [V0.3 后端与开发清单](docs/V0.3_BACKEND_AND_NEXT_STEPS.md)。

V0.3 已有本机数据库、服务端报价与状态校验、校区隔离、审核和人工派单、并发接单保护及审计记录。测试身份可以直接切换，**没有真实登录**，只能在自己的电脑上用虚构数据测试。

## 入口

- `web/` + `server/`：V0.3 本机运行的业务测试系统。
- `demos/`：V0.1 和 V0.2 历史单文件演示，可直接在浏览器打开。
- `docs/`：产品设计、校区运营、站点核验与上线验收规范。
- Base44 历史在线原型：<https://app.base44.com/apps/6ad5df9cb5d27854baffa1a7/editor/preview>，不参与 V0.3 运行。

## 当前已核实的内容（2026-10-19）

- 双校区及七个宿舍苑区的基础配置；
- 三个**未核实或未授权**的取件站候选记录，默认禁止真实下单；
- 本仓库 V0.2 独立演示版已用虚构数据跑通模拟下单、模拟支付、代取员接单、人工派单及确认收货；仅为单浏览器交互，见 [测试记录](docs/TEST_REPORT_V0.2.md)。
- Base44 已通过连接器核实有实体模型和初步访问规则；在线页面及完整源码因登录验证与 Builder 套餐限制未完成实测。

**注意：** 仓库不包含 Base44 在线应用完整源码，也没有与其自动同步。V0.3 是重新建立的本地后端原型，不能冒充生产系统。[历史同步核验](docs/GITHUB_SYNC_GUIDE.md)与[小程序迁移方案](docs/WECHAT_MINIPROGRAM_MIGRATION.md)分别记录背景和后续步骤。

**持续维护：** 每日检查本地源代码、演示、文档和配置的安全变更并归档到本私有仓库；不会自动导入 Base44 网页的改动。详见[维护说明](docs/MAINTENANCE.md)。

## 适用校园

| 校区 | 宿舍苑区（待逐楼栋核对） | 快递站点 |
|---|---|---|
| 成龙校区 | 东苑、西苑 | 待实地核验/获准开放 |
| 狮子山校区 | 博学苑、重德苑、聚贤苑、尚美苑、务实苑 | 网络候选点，待实地核验和授权 |

## 优先级

1. 学校/快递站确认有偿第三方代取权限、精确位置及交接规则；
2. 完成学生账号和代取员身份的后端权限校验；
3. 实现本校区派单与抢单原子性、订单状态机、异常单/售后；
4. 经营主体、微信小程序认证及微信支付商户接入；
5. 双校区灰度测试后再开放真实下单。

完整路线见 [ROADMAP.md](ROADMAP.md)，版本历史见 [CHANGELOG.md](CHANGELOG.md)，安全说明见 [SECURITY.md](SECURITY.md)。
