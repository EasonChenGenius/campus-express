# 校园快取通 Campus Express

面向四川师范大学**成龙校区**与**狮子山校区**的校园快递代取平台（开发中）。目前独立开发，不再依赖 Base44。

**当前版本：V0.5.3 本地业务与微信小程序开发演示版。真实下单、身份认证、支付和正式运营均未开放。**

## 先在电脑浏览器体验

在 macOS 上双击项目根目录的 **`启动校园快取通.command`**，即可启动本机服务并打开浏览器。请保持终端窗口运行；关闭窗口后本机演示会停止。也可以安装 Node.js 24.12 或更新版本，在项目目录运行 `npm start`，再打开 <http://127.0.0.1:3000>。无需安装 npm 包。直接双击 `web/index.html` 只会显示启动指引，因为订单操作需要本机后端。

使用虚构测试账号、`TEST-123456` 等测试码；选择宿舍苑区后会自动显示楼下当面交接位置。预约可选今天或明天 09:00–19:00 的一小时档，已过期或已约满的时段自动隐藏；网页后台可按校区调整每小时测试名额。运行 `npm test` 可执行后端验证。格式依据与解释见[取件码和交接位置说明](docs/PICKUP_CODE_AND_HANDOFF.md)，完整开发范围见 [V0.3 后端与开发清单](docs/V0.3_BACKEND_AND_NEXT_STEPS.md)。

后端已有本机数据库、服务端报价与状态校验、校区隔离、审核和人工派单、并发接单保护、异常订单、代取员接单额度和审计记录。主管可在网页后台处理异常及超过 30 分钟无人接单的待办。测试身份可直接切换；演示会话 30 分钟后失效，切换时撤销旧令牌，**但没有真实登录**，只能在自己的电脑上用虚构数据测试。[下一步方案与 GitHub 参考](docs/V0.5_CHOICES_AND_GITHUB_REFERENCES.md)列出业务路线，[微信身份与上线方案](docs/WECHAT_IDENTITY_AND_LAUNCH.md)列出正式登录的开发步骤。

异常上报、暂停、核实及处理结果说明见[异常处理流程](docs/EXCEPTION_WORKFLOW.md)。演示版需要人工刷新查看结果，目前没有自动通知、客服或退款。

## 在微信开发者工具体验 V0.5

1. 保持电脑终端中的 `npm start` 运行；接口只监听 `127.0.0.1:3000`。
2. 安装并打开微信开发者工具，导入本仓库的 `miniprogram/` 文件夹。项目配置中的 `touristappid` 仅供工具内演示；若工具要求测试 AppID，使用自己申请的测试 AppID，不要把正式 AppSecret 放入项目。
3. 仅在开发者工具模拟器中选择“学生甲（测试）”或“学生乙（测试）”，输入 `TEST-123456` 等虚构码创建订单；切换到同校区已审核代取员接单并更新进度；切回学生确认。
4. 代取员“待审核”账号用于验证拒绝访问。已审核代取员可切换上线状态，并在订单详情上报测试异常。管理员仍在电脑浏览器 `http://127.0.0.1:3000` 处理异常和接单上限。重复提交同一表单会复用请求编号，断网后可保持表单重试。

本机回环地址只能供同一电脑上的开发者工具使用；该项目没有可供手机或其他人访问的测试服务器，也未完成微信真实登录。**不要把开发演示包发布为体验版或正式版。** 小程序接口与人工验收步骤见 [V0.5 接口补充](docs/V0.5_API_CONTRACT.md)；进入封闭试用前的条件见 [封闭试用准备清单](docs/CLOSED_PILOT_READINESS.md)。

## 入口

- `web/` + `server/`：本机运行的业务测试系统与管理员网页。
- `miniprogram/`：学生和代取员共用的原生微信小程序开发演示。
- `demos/`：V0.1 和 V0.2 历史单文件演示，可直接在浏览器打开。
- `docs/`：产品设计、校区运营、站点核验与上线验收规范。
- Base44 历史在线原型：<https://app.base44.com/apps/6ad5df9cb5d27854baffa1a7/editor/preview>，不参与当前版本运行。

## 当前已核实的内容（2026-10-19）

- 双校区及七个宿舍苑区的基础配置；
- 三个**未核实或未授权**的取件站候选记录，默认禁止真实下单；
- 本仓库 V0.2 独立演示版已用虚构数据跑通模拟下单、模拟支付、代取员接单、人工派单及确认收货；仅为单浏览器交互，见 [测试记录](docs/TEST_REPORT_V0.2.md)。
- Base44 已通过连接器核实有实体模型和初步访问规则；在线页面及完整源码因登录验证与 Builder 套餐限制未完成实测。

**注意：** 仓库不包含 Base44 在线应用完整源码，也没有与其自动同步。当前系统是独立建立的本地原型，不能冒充生产系统。[历史同步核验](docs/GITHUB_SYNC_GUIDE.md)与[小程序迁移方案](docs/WECHAT_MINIPROGRAM_MIGRATION.md)分别记录背景和后续步骤。

**持续维护：** 每日检查本地源代码、演示、文档和配置的安全变更并归档到本私有仓库；不会自动导入 Base44 网页的改动。详见[维护说明](docs/MAINTENANCE.md)。

## 优先级

1. 学校/快递站确认有偿第三方代取权限、精确位置及交接规则；
2. 完成学生账号和代取员身份的后端权限校验；
3. 实现本校区派单与抢单原子性、订单状态机、异常单/售后；
4. 经营主体、微信小程序认证及微信支付商户接入；
5. 双校区灰度测试后再开放真实下单。

完整路线见 [ROADMAP.md](ROADMAP.md)，版本历史见 [CHANGELOG.md](CHANGELOG.md)，安全说明见 [SECURITY.md](SECURITY.md)。
