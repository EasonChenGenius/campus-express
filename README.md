# 校园快取通 Campus Express

面向四川师范大学**成龙校区**与**狮子山校区**的校园快递代取平台（开发中）。

**项目状态：原型 / 内部测试，不具备真实支付或正式运营条件。**

## 入口

- Base44 在线应用编辑与预览：<https://app.base44.com/apps/6ad5df9cb5d27854baffa1a7/editor/preview>
- 本仓库 `demos/`：独立 HTML 交互演示，可用浏览器直接打开，但不支持多人实时协同。
- `docs/`：产品设计、校区运营、站点核验与上线验收规范。

## 当前已核实的内容（2026-10-19）

- 双校区及七个宿舍苑区的基础配置；
- 三个**未核实或未授权**的取件站候选记录，默认禁止真实下单；
- 本仓库 V0.2 独立演示版已用虚构数据跑通模拟下单、模拟支付、代取员接单、人工派单及确认收货；仅为单浏览器交互，见 [测试记录](docs/TEST_REPORT_V0.2.md)。
- Base44 已通过连接器核实有实体模型和初步访问规则；在线页面及完整源码因登录验证与 Builder 套餐限制未完成实测。

**注意：** 这个 GitHub 整理包不包含 Base44 在线应用完整源码，也没有自动同步。`demos/` 是独立演示，不可冒充生产系统。[同步核验](docs/GITHUB_SYNC_GUIDE.md)与[小程序迁移方案](docs/WECHAT_MINIPROGRAM_MIGRATION.md)分别记录后续步骤。

## 适用校园

| 校区 | 宿舍苑区（待逐楼栋核对） | 快递站点 |
|---|---|---|
| 成龙校区 | 东苑、西苑 | 待实地核验/获准开放 |
| 狮子山校区 | 博学苑、重德苑、聚贤苑、尚美苑、务实苑 | 网络候选点，待实地核验和授权 |

## 优先级

1. 学校/快递站确认有偿第三方代取权限、精确位置及交接规则；
2. 完成学生账号和代取员身份的后端权限校验；
3. 实现本校区派单与抢单原子性、订单状态机、异常单/售后；
4. 经营主体、微信小程序认证及微信支付商户接入；
5. 双校区灰度测试后再开放真实下单。

完整路线见 [ROADMAP.md](ROADMAP.md)，版本历史见 [CHANGELOG.md](CHANGELOG.md)，安全说明见 [SECURITY.md](SECURITY.md)。

不是四川师范大学官方发布的系统，不代表学校或站点批准合作。试运营数据及演示金额都是样例，不能作为已生效服务承诺。

不要把学生手机号、取件码、身份证、微信支付私钥、商户证书或真实订单数据提交到 GitHub，即便是私有仓库。
