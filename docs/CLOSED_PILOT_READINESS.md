# 封闭试用准备清单

更新时间：2026-10-23。当前状态：**未达到封闭试用门槛**。本文件列出进入真实人员试用前需要完成并留证的事项；V0.5 的演示小程序和 `127.0.0.1` SQLite 后端不能直接部署给学生。

## 产品与现场

- [ ] 学校/校区明确第三方代取的允许范围；每个快递站单独核实有偿代取、取件凭证和站点交接规则。保留授权记录。
- [ ] 核实两个校区的站点位置、营业时间、苑区及楼下公共交接点；仅经授权站点可被服务端设为开放。
- [ ] 制定禁运品、代取失败、破损/遗失、联系不上学生、超时改派、投诉赔付和客服响应流程，并安排负责人员。

## 身份、隐私与数据

- [ ] 获得小程序主体和 AppID；由后端通过微信登录凭证换取身份，服务器绑定学生、代取员、校区与角色。删除试用环境的 `/api/demo/*` 接口；代取员身份及资格由管理员审核，不能自行改角色。
- [ ] 明确实际需要收集的资料及保存期限，完成隐私告知、用户删除/注销流程；取件码单独加密存储，日志、通知及 GitHub 中不得包含真实取件码或联系方式。
- [ ] 建立正式管理员登录、最小权限和操作审计。会话设置失效时间，支持退出与撤销；对越权、重放、并发和异常输入做安全测试。

## 服务、订单与运营

- [ ] 准备独立 HTTPS 测试服务和小程序允许的请求域名；与本机演示数据、账号、密钥完全隔离。配置上线时以[腾讯云小程序网络说明](https://cloud.tencent.com/document/product/379/81340)及微信平台当时的官方要求核验。
- [ ] 将订单和审计写入适合多实例运行的正式数据库，完成事务、数据库迁移、备份、恢复演练和监控告警；测试 20 名不同代取员抢同一单、断网重试及服务重启。
- [ ] 完成代取员上线/下线、限单、异常件、改派、时段容量、通知和人工处理队列。建立值班和故障停止服务流程。
- [ ] 在限定测试人员和授权站点范围内完成真机与弱网验收，记录负责人、日期、证据和未解决问题。

## 收款与发布

- [ ] 当前所有订单继续为 `demo_not_paid`，不接真实支付。若将来需要收费，先核实经营主体、商户资质、支付通知验签、查单、退款和对账，再由项目负责人单独确认开放。
- [ ] 封闭试用、真实下单和正式运营分别进行独立验收与负责人确认；不能把开发者工具模拟器通过当作真实试用通过。

本仓库只存放虚构样例与代码。检查清单中的身份证明、协议、密钥、真实订单、数据库备份等材料应保存在受控的私有系统，不上传 GitHub。
