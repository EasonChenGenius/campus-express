# 代取员入驻、验证码与进度更新

更新时间：2026-10-26。当前系统为 V0.7.0 **本机虚构数据演示**，不允许真实学生或代取员注册运营。

## 现在可以怎样体验

1. 以学生测试身份打开网页或小程序，提交“申请成为代取员（测试）”。不输入真实个人资料。
2. 成龙主管只审核成龙申请；狮子山申请由总管理员测试身份处理。通过后会生成新的代取员测试身份，默认下线。
3. 在测试账号选择器中切换到新代取员身份，上线后才可查看本校区任务摘要和接单。接单前不返回取件码和具体楼栋；接单后按服务端权限取得必要详情。
4. 代取员在订单详情依次确认取件、开始配送和楼下交接；学生确认收货。异常由本校区主管处理。所有状态由后端写入，抢单和派单仍由服务端校验。

**身份边界：**目前测试账号可直接切换，申请审核只是演示流程，不能证明申请人真实身份或代取资格。真实版本应先完成小程序 `wx.login` 的服务端校验、身份绑定、代取员审核材料和管理账号保护；角色与校区由服务器保存，不接受客户端自行声明。参考[微信身份实施顺序](WECHAT_IDENTITY_AND_LAUNCH.md)及[身份权限矩阵](IDENTITY_PERMISSION_MATRIX.md)。

## 验证码是否真实

**不是。** 现在网页注册和找回密码只接受 `TEST-` 虚构号码，六位码由后端生成后直接显示在当前页面，`delivery: ON_PAGE_ONLY`，没有短信网关、短信签名、短信费用或真实号码验证。小程序目前也没有可信微信登录。

正式试用时，先决定是否确需手机号：微信身份标识可以承担登录，手机号可仅用于必要联系。若确需短信验证码，应由服务端对接受控短信服务，使用审核通过的签名和模板，限制号码/IP/设备的频率与总费用，验证码限时、限次、单次使用；密钥不得放入小程序或 GitHub。腾讯云当前的[短信使用须知](https://cloud.tencent.com/document/product/382/13444)与[短信安全说明](https://cloud.tencent.com/document/product/382/13303)列出了签名、模板和防盗刷要求，实际接入时需再次核验。

## 进度有多及时

- 后端收到有效操作后立即保存状态；操作人在当前页面会立即看到返回结果。
- 其他人打开的小程序页面在**可见时约每 15 秒**重新读取；手动刷新也可立即读取。页面隐藏、手机断网或服务端停止时不会继续同步。
- 现在**没有**后台推送、订阅消息、送达保证、离线补偿或客服通知，因此不能承诺实时提醒。正式试用需评估微信订阅消息的用户授权和模板要求，配合状态变更事件与失败重试。腾讯云[小程序订阅消息说明](https://cloud.tencent.com/document/product/1301/103770)指出发送前需要用户主动授权；实际微信平台规则需在接入时复核。
- 真机联网前需要可信 HTTPS 域名并配置小程序允许的请求域名；本机 `127.0.0.1` 仅用于开发工具演示。参考腾讯云的[小程序网络说明](https://intl.cloud.tencent.com/zh/document/product/1219/61745)。

## 封闭试用前还需验收

真实代取员的身份和校区、站点授权、培训和保险/异常责任规则；真实登录与管理员权限；页面后台切换和弱网恢复；重复点击、并发抢单、时段满额和交接失败；隐私告知、数据删除、备份恢复、审计和真机体验。未完成前不开放真实下单、真实支付或正式运营。
