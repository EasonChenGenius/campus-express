# 私有 GitHub 持续维护方式

生效日期：2026-10-21。项目负责人选择不升级 Base44 套餐，继续维护 `EasonChenGenius/campus-express` 私有仓库。

## 更新范围

- 每天上午 9 点（Asia/Shanghai）检查本工作目录中的独立源代码、测试、演示、README、CHANGELOG、ROADMAP、配置与文档。
- 仅当本地文件确有安全变更时，更新仓库中的对应文件并核对内容；没有变更则不创建空提交。
- 每次上传前检查真实学生信息、真实取件码、密钥、支付凭据和生产订单数据。只修改本仓库。

## 明确限制

Base44 项目目前 `git_remote_source=s3`，直接读取项目文件返回 `PREMIUM_REQUIRED`。本维护流程不读取 Base44 在线源码，也不是 Base44 与 GitHub 的双向同步。仅在 Base44 编辑器中做的更改，不会自动出现在本仓库；如需将其记录在 GitHub，必须另行取得可审查的导出内容或在本地实现相应更新。

真实支付、真实下单和正式运营保持关闭，除非项目负责人以后明确批准并完成上线验收。
