# 取件码与当面交接位置：V0.3.1 调整依据

更新于 2026-10-21。**这不是四川师范大学两校区现有驿站的已核实规则。**正式业务必须逐站确认取件规则、授权与可用的交接位置。

## 查到的格式

没有证据支持“所有快递取件码只有一种格式”。已有公开的校园服务说明显示：

- [青岛工学院后勤服务中心](https://hqc.qit.edu.cn/info/1009/2282.htm)给出的驿站示例为 `1-2-0023`，含义是货架号、层数、包裹条码后四位。
- [浙江大学后勤集团](https://zulg.zju.edu.cn/info/1297/8499.htm)也说明过“货架号-层数-包裹条码末四位”的形式，同时指出部分特殊件不按该流程取件。
- [温州大学电气与电子工程学院的服务提示](https://eee.wzu.edu.cn/info/1182/3383.htm)展示过字母数字混合的短信取件码。该示例来自另一套服务系统，说明不宜把取件码限制为纯数字。
- [国家邮政局报道](https://www.spb.gov.cn/gjyzj/2022wjmtbdb/202411/23face05721745729eee2a6108b02d9f.shtml)描述过校内驿站按货架、层、位置找件；[菜鸟官方页面](https://www.cainiao.com/technology-cainiao-app.html)还列出身份码、扫码、出库码等多种取件方式。

检索四川师范大学两校区的公开页面后，未找到能够确认**当地每个驿站**实际取件码格式的官方说明；因此不把其他学校的示例写成川师规则。

因此，当前测试表单提供三种**虚构**示例：`TEST-123456`（数字）、`TEST-5-2-0042`（货架-层-末四位）、`TEST-9VK518`（字母数字）。`TEST-` 前缀是本项目的安全测试标记，不属于真实驿站格式。服务端仍拒绝没有该前缀的输入。不能把这些示例当作四川师范大学站点实际取件规则；待站点核验后，再按站点的真实流程设计授权取件与身份码处理。

## “楼下交接点”到底是什么

**取件地点**是包裹所在的快递站，代取员在那里取包裹。**交接位置**是代取员送来之后，学生到宿舍楼下与其见面、确认收到包裹的公共位置。交接位置不等于快递站，也不需要填写宿舍房间号。

为避免让测试用户猜地址，V0.3.1 不再要求手填交接点。学生选择宿舍苑区后，系统自动给出“东苑楼下公共入口（测试）”等虚构示例。正式版需要先现场核对各苑区可进入范围、指定入口和夜间规则，再开放真实交接位置。
