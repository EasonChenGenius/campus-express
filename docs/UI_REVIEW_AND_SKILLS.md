# 网页界面审查与 GitHub 设计参考（2026-10-25）

本次仅优化本机演示界面。业务权限、服务端校验、虚构数据限制与真实支付关闭状态保持不变。界面采用此前选定的 **A：简洁卡片布局 + C：柔和冷色**。

## 本轮发现并修复

| 问题 | 调整 | 本机检查 |
|---|---|---|
| 入口页顶部流程图过高，较窄窗口看不到身份选择 | 压缩首页高度、加直达入口按钮、提前显示三个身份卡；手机宽度隐藏装饰性流程图 | 744px 宽浏览器截图复核，身份入口在首屏可见 |
| 主管异常待办排在订单列表后 | 按角色改变工作台顺序；主管和总管理员先看到待办 | 主管测试账号进入后，待办显示在订单列表前 |
| 学生、代取员、主管页面缺少页内定位 | 各角色新增对应的快速导航 | 主管页面检查到待办、订单、时段、审核、记录入口 |
| 绿色元素过于集中、状态不够容易区分 | 使用低饱和紫蓝、薄荷绿和中性背景；异常、已完成等状态分别着色 | 本机浏览器目视检查，服务端测试验证新样式正常提供 |
| 键盘访问与动态偏好不够明确 | 增加跳到主要内容、可见焦点和减少动态效果的样式 | 代码检查；仍需后续键盘实测与真机检查 |

## 参考项目

- [TDesign 小程序零售模板](https://github.com/Tencent/tdesign-miniprogram-starter-retail)：参考商品/订单信息层级与紧凑卡片布局。已验证仓库说明的 MIT 许可。**没有复制模板代码或图片**。
- [TDesign 小程序组件](https://github.com/Tencent/tdesign-miniprogram)：后续小程序页面可评估组件使用；需先核对与原生小程序项目的兼容性和包体积。
- [Vant Weapp](https://github.com/youzan/vant-weapp)：表单、弹窗和状态反馈的备选组件库。暂未安装。

## GitHub 上的设计 skills

- [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)：参考有主题的视觉设计、版式和文字层级建议。这是面向其自家工具的 skill，本项目仅阅读建议，未安装或复制代码。
- [Vercel web-design-guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines)：参考清楚的表单标签、可见焦点、语义化导航与状态反馈。本项目仅阅读建议，未安装。
- 本轮实际使用本机已有的 Product Design `audit` skill 做逐屏审查；该 skill 与以上 GitHub 项目无依赖关系。

以上仓库是设计参考，不代表其作者参与或认可校园快取通。正式小程序应继续使用当前业务接口与服务端权限规则，不能直接套用电商模板的支付流程。
