# V0.4 本机演示接口与小程序验收

更新时间：2026-10-22。接口版本 `apiContract: 1`。只供 `127.0.0.1`、虚构测试账号、虚构站点和 `TEST-` 取件码使用。没有真实微信登录、收款或履约能力。

## 启动与会话

- `npm start` 启动本机服务；`GET /api/capabilities` 返回 `version: 0.4.0`、`mode: LOCAL_DEMO_ONLY`、`apiContract: 1`、`realOrders: false`、`realPayment: false`、`realAuthentication: false`、`closedPilotReady: false`。小程序只接受这一演示模式。
- `GET /api/demo/accounts` 列出测试账号；`POST /api/demo/login` 接收 `{ "accountId": "student-a" }`，返回临时 Bearer token 和测试用户。重启后端后内存会话失效。此接口不得放到试用或生产环境。
- 其余接口要求 `Authorization: Bearer <token>`。401 时小程序清除内存会话并返回身份选择页。错误响应为 `{ "code": "UNAUTHORIZED", "error": "请先选择测试身份" }` 一类对象。稳定错误码包括 `VALIDATION_ERROR`、`FORBIDDEN`、`NOT_FOUND`、`CONFLICT`、`NETWORK_ERROR`（仅客户端）和 `INTERNAL_ERROR`。

## 学生与代取员共用的订单契约

| 接口 | 调用者 | 行为 |
|---|---|---|
| `GET /api/catalog` | 已选测试身份 | 取得双校区苑区、虚构站点及开放标记；开放标记均为 false。 |
| `POST /api/orders` | 学生 | 输入 `requestId,campus,stationId,zone,pickupCode,qty,size,speed,slot`；服务端校验校区与 `TEST-` 码并计算金额，始终设为未付款。交接点由苑区生成，不接受客户端填写。 |
| `GET /api/orders` | 学生或已审核代取员 | 学生仅看本人；代取员只看本校区待接单摘要和本人已接任务。 |
| `GET /api/orders/{id}` | 有权查看的用户 | 取订单详情。代取员成功接单前不返回取件码、学生编号和交接位置。 |
| `POST /api/orders/{id}/accept` | 已审核代取员 | 本校区待接单任务原子接单。重复或竞争失败返回 409。 |
| `POST /api/orders/{id}/progress` | 本单代取员 | `{ "status": "picked" }`、`delivering`、`delivered` 顺序推进。 |
| `POST /api/orders/{id}/confirm` | 下单学生 | 已交接后确认完成。 |
| `POST /api/orders/{id}/cancel` | 下单学生 | 仅待接单可取消。 |

`requestId` 是单个学生创建订单的幂等键。相同编号和相同内容返回原订单；相同编号配不同内容返回 409。小程序将待提交的**虚构测试表单**和编号保存在开发者工具本地，网络失败后原样重试，成功后清除。更改表单内容会生成新编号。

管理员与校区主管继续使用网页的 `GET /api/couriers`、`POST /api/couriers/{id}/approval`、`POST /api/orders/{id}/assign` 和 `GET /api/audit`；服务端按角色及校区校验。网页管理员身份同样只是测试账号。

## 人工验收步骤

1. 运行 `npm test`，确认后端和小程序请求层测试通过；运行 `npm start`，打开电脑浏览器确认网页管理员仍可派单。
2. 在微信开发者工具导入 `miniprogram/`，模拟器用学生甲、成龙代取员甲完成创建、接单、取件、配送、交接、确认；用学生乙、狮子山代取员甲重复。待接单列表不得显示取件码。
3. 用待审核代取员测试拒绝访问；用不同校区代取员查看任务，确认只出现本校区任务；用学生在待接单时取消。
4. 暂停本机服务后提交测试订单，确认页面保留表单和请求编号；恢复服务后不改表单重试，订单只出现一次。重启本机服务使 token 失效，刷新订单时应返回身份选择页。

当前环境若未安装微信开发者工具，只能完成自动化接口测试与静态检查；模拟器和真机验收必须在安装工具及取得测试 AppID 后记录结果，不得写成已通过。
