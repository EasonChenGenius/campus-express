# V0.6.1 楼栋接口补充

`GET /api/capabilities` 返回 `version: 0.6.1`、`apiContract: 8`、`mode: LOCAL_DEMO_ONLY`；真实身份、短信、订单和支付仍关闭。原账号接口见 [V0.6 契约](V0.6_API_CONTRACT.md)。

- `GET /api/catalog` 新增 `campusBuildings`：`chenglong.东苑` 为东1—东13；`chenglong.西苑` 为空数组，表示楼号待核实。其他苑区也未录入楼栋。
- `POST /api/orders` 新增 `building`。东苑必须为东1—东13；尚未核实楼号的苑区仅接受 `null`、空串或省略。继续由服务端校验校区、苑区、测试站点、时段与 `TEST-` 虚构码。
- 订单详情和学生、管理员视图返回 `building`；代取员接单前的任务池不返回具体楼栋、交接点或取件码。接单后才可查看。
- `handoff` 为服务端生成的“苑区 + 楼栋 + 楼下公共入口（演示位置，待核实）”。不得视为现场核验结果。
- 旧本机 SQLite 订单自动增加可空 `building` 列，旧订单保持原有交接文字。

当前版本只供单机演示。正式业务需要另行核实楼栋与交接点、授权站点、可信微信身份与隐私告知。
