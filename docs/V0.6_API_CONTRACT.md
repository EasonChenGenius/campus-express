# V0.6 本机演示账号接口

`GET /api/capabilities`：`version: 0.6.0`、`apiContract: 7`、`mode: LOCAL_DEMO_ONLY`、`realAuthentication: false`、`realSms: false`、`realOrders: false`、`realPayment: false`。已有订单与异常接口见 [V0.5 契约](V0.5_API_CONTRACT.md)。

| 接口 | 演示行为 |
|---|---|
| `POST /api/demo/send-code` | `{phone,purpose}`，`purpose` 为 `register` 或 `reset`。只接受 `TEST-` 加 11 位演示号码。返回 `demoCode`、`delivery: ON_PAGE_ONLY`；无短信发送。5 分钟有效、60 秒发送间隔。 |
| `POST /api/demo/register` | `{phone,code,password,campus}`。验证码一次性使用；校区只能是成龙/狮子山，角色由服务端固定为学生。返回测试令牌与用户。 |
| `POST /api/demo/password-login` | `{phone,password}`。密码验证失败累计 5 次后锁定 15 分钟；成功返回 30 分钟测试令牌。 |
| `POST /api/demo/reset-password` | `{phone,code,password}`。一次性验证码成功后更换摘要并撤销该账号全部旧会话。 |
| `POST /api/demo/login` | 原有虚构身份一键切换，继续用于学生、代取员和管理员角色流程演示。此接口不能部署给真实用户。 |

测试号码不是真实手机号。新注册账号仅在本机 SQLite 中持久化，密码使用随机盐 `scrypt` 摘要；验证码只以进程密钥生成的摘要保存，重启服务后旧验证码不能再验证。上述措施不能替代正式短信、微信身份绑定、网络安全和隐私合规。页面及权限说明见[电脑网页账号演示](WEB_AUTH_DEMO.md)。
