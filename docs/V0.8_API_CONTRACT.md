# V0.8.0 本机演示接口补充

`GET /api/capabilities` 返回 `version: 0.8.0`、`apiContract: 11`、`mode: LOCAL_DEMO_ONLY`，并持续声明真实订单、支付、短信及可信认证均未启用。其余接口见 [V0.7.1 契约](V0.7.1_API_CONTRACT.md)。

## 楼下当面交接码

- `POST /api/orders/{id}/handoff-code`：仅订单所属学生、订单处于 `delivering` 时可调用。返回 `{demoHandoffCode, expiresInSeconds: 300, delivery: "ON_PAGE_ONLY"}`；交接码只在本次响应显示，服务端保存 HMAC 摘要，订单详情和审计不返回明文。30 秒内重复生成返回 429；新码替换旧码。演示服务重启后旧码失效，学生可重新生成。
- `POST /api/orders/{id}/progress` 当 `status: "delivered"` 时，代取员必须额外提交六位 `handoffCode`。仅本单已审核代取员、当前状态为 `delivering`、验证码未过 5 分钟且未超 5 次错误时才能成功。成功后立即清除摘要，重复提交返回 409。错误码返回 400，过期或未生成返回 409，错误次数用尽返回 429。
- 交接码用于**演示当面核对**，不是快递站取件码；不得在短信、日志、订单列表或 GitHub 中传播真实版本的码。学生仍需在 `delivered` 后确认订单，异常上报仍可暂停并交给后台核实。

本接口只用于本机虚构流程。正式环境应独立设计可靠的交接凭证、身份及事件审计，不能直接部署本机服务。
