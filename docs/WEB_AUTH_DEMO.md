# 电脑网页的角色与账号演示

更新时间：2026-10-23，版本 V0.6.0。此页与所有 `/api/demo/*` 接口**只供本机虚构数据演示**。本项目仍没有真实微信登录、短信服务或正式管理员认证，不能让真实学生注册。

## 三类工作台

| 入口 | 本机演示方式 | 可做的事 | 正式版要求 |
|---|---|---|---|
| 学生 | 一键选择虚构测试身份；或用 `TEST-` 演示号码注册/密码登录 | 本人订单、预约、取消、确认、交接后上报异常 | 微信可信身份绑定、校区核验、隐私告知 |
| 代取员 | 一键选择虚构代取员身份 | 本校区任务池、接单、进度、异常、上线/下线 | 申请与人工审核，不可自行赋权 |
| 校区主管/总管理员 | 一键选择虚构管理身份 | 本校区或双校区派单、审核、异常待办、容量、审计 | 独立强身份认证、最小权限、操作复核 |

页面上方三个入口卡片帮助选择角色；实际可见范围仍由服务端按身份、校区、订单归属判断。测试下拉框保留，方便演示不同角色。它不是正式登录，任何能访问本机演示服务的人都能选择测试身份。

## 学生账号演示步骤

1. 在“注册学生”填写 `TEST-13800000001` 这类**带前缀的虚构号码**，选择成龙或狮子山校区。点击“显示演示验证码”；六码直接显示在本机页面，5 分钟有效，60 秒内不可重复获取。它没有被发送到手机。
2. 设置 10–72 位、无空白字符的**演示密码**。服务端只存密码的加盐 `scrypt` 摘要；账号与摘要仅保存在本机 `data/` 数据库，该目录不进入 GitHub。注册成功即进入学生工作台，无法选择代取员或管理员角色。
3. 在“密码登录”输入同一演示号码和密码。连续 5 次错误后暂时锁定 15 分钟；也可以通过找回密码重设。
4. 在“找回密码”再次获取本机演示验证码并设置新密码；成功后旧登录会话全部失效。验证码只可使用一次，错误尝试最多 5 次。

请不要填写真实手机号、常用密码、真实取件码或其他个人资料。若误填，应停止使用并删除本机 `data/` 测试数据库；删除前先确认无需保留演示订单。

## 正式版仍需开发

- 学生与代取员优先采用微信小程序可信登录和服务端角色绑定；如确需手机短信登录，需要短信服务商、发送凭据、风控、隐私告知、费用预算及实名使用场景，再由项目负责人批准启用。
- 正式管理后台必须使用独立认证，不暴露“选择总管理员测试身份”入口。
- 正式数据库要支持备份、加密、审计、账号注销和个人资料删除；不能把本机演示账号表直接搬到生产环境。
